# Product Metrics Snapshot

Source type: weekly product metrics for a prototype used by four internal teams.

Metric: 14 recurring research briefs were generated in the last two weeks.

Metric: 9 of 14 briefs had at least one source-context edit after the first generated draft.

Metric: 7 of 14 briefs used a second run to compare prompt or context changes.

Metric: 5 of 14 briefs were shared outside the immediate working group.

Signal: The most common successful path was "edit context, update outputs, publish a link."

Evidence: Users with no command-line experience completed the context-editing step when presented with a document editor and a single Update button.

Concern: The current artifact viewer must render Markdown as a report, not raw text, for non-technical reviewers to trust it.

Concern: The first demo must avoid looking like a dashboard for manifests; the report should be the center of the experience.
